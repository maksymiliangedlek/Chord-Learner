# Szkoła Akordeonu im. Zapałki

**Live:** https://szkolaakordeonuimzapalki.vercel.app/

A minimal accordion chord trainer with an Apple-style glass UI.

## Features

- **Practice** — metronome with random chord changes from your selected set; adjustable BPM (slider or number input)
- **Drunk mode** — flying digits across the screen; drag them into the tempo field to set BPM
- **Learn** — browse major, minor, 7th, and sus4 chords with a piano keyboard, fingering tips, and short descriptions

## Stack

React + TypeScript + Vite. Web app lives in `chord-learner-web/`.
